# 📋 Guía de Uso - Plantilla de Cotización ESD Sikafloor 260

## 📌 Descripción General

Esta plantilla de cotización fue desarrollada analizando y combinando los mejores elementos de 4 cotizaciones previas. Proporciona una estructura profesional, clara y completa para presentar propuestas de Sistemas de Control Electrostático (ESD) con Sikafloor 260 de Sika.

---

## 🎯 Elementos Clave de la Plantilla

### 1. **ENCABEZADO**
- Título profesional "COTIZACIÓN"
- Línea divisoria con color corporativo
- Tabla de información básica

**Campos a completar:**
- `[___-S-25]` → Número de cotización (ej: 335-S-25)
- `[____] de [_________]` → Fecha completa
- `[NOMBRE DE EMPRESA]` → Empresa cliente
- `[NOMBRE / CARGO DEL CONTACTO]` → Persona de contacto

### 2. **INTRODUCCIÓN**
- Presenta formalmente la propuesta
- Especifica el cumplimiento de norma ANSI S20.20
- Menciona lecturas de conductividad (<1.0 x 10⁹)

**Elemento fijo:** No requiere cambios, es estándar.

### 3. **ESPECIFICACIONES TÉCNICAS DEL SISTEMA ESD**
Tabla que especifica:
- **Clasificación:** Sistema Disipativo (1 x 10⁵ a 1 x 10⁹ Ω)
- **Norma:** ANSI S20.20-2007/2014
- **Superficie:** *(editable)* Ingresa en m² y/o Ft²

**Campos a completar:**
- `[_________] m² / [_________] Ft²` → Área del proyecto

### 4. **DESCRIPCIÓN DEL TRABAJO**
Lista detallada de 9 pasos del proceso de aplicación:
1. Preparación mecánica por desbaste
2. Reparación de grietas/hoyos
3. Limpieza y aspirado
4. Capa de epóxico 100% sólidos (aislamiento)
5. Instalación de electrodos y cintilla de cobre
6. Aplicación de primer conductivo SIKAFLOOR 220W
7. Secado (24 horas)
8. Aplicación de SIKAFLOOR 260 ESD final (12 milésimas)
9. Secado (24 horas)

**Elemento fijo:** Generalmente no requiere cambios, pero puedes ajustar espesores (milésimas) si es necesario.

### 5. **COTIZACIÓN**
Tabla de precios con estructura flexible:

| Concepto | Cantidad | Precio (USD) |
|----------|----------|--------------|
| Precio por m² | [_____] | [$ _______] |
| Subtotal | - | [$ _______] |
| IVA (16%) | - | [$ _______] |
| Otros costos* | - | [$ _______] |
| **TOTAL** | - | **[$ _______]** |

**Cómo completar:**
1. Ingresa el precio por m² (consultado con Sika/proveedores)
2. Multiplica por la superficie para obtener subtotal
3. Calcula IVA al 16% del subtotal
4. Suma otros costos (fianzas, permisos, cuotas sindicales si aplica)
5. **TOTAL** = Subtotal + IVA + Otros costos

**Ejemplo:**
- Superficie: 2,500 m²
- Precio/m²: $4.50 USD
- Subtotal: 2,500 × 4.50 = $11,250
- IVA (16%): $1,800
- Otros: $200
- TOTAL: $13,250

### 6. **GARANTÍA**
Sección que cubre:
- Período: 1 año
- Cobertura: Material y mano de obra
- Limitaciones (fallos de sustrato, presiones hidrostáticas, químicos, mal uso)
- Conductividad garantizada por SIKA Mexicana
- Responsabilidad de instalación de tierras

**Elemento fijo:** Incluye todas las cláusulas importantes. Solo personaliza si el cliente solicita cambios específicos.

### 7. **OBSERVACIONES Y CONSIDERACIONES**
14 puntos clave que incluyen:

✓ **Comerciales:**
- Precios en USD sin IVA
- Validez de 30 días
- Requiere OC o Contrato

✓ **Financieras:**
- 60% anticipo, resto en avances
- Tiempo de entrega: 6-10 semanas

✓ **Técnicas:**
- Requiere corriente 220V trifásica
- Necesita iluminación, agua, clima controlado
- Área cerrada y exclusiva
- Parámetros de temperatura/humedad según SIKA
- Tierras proporcionadas por cliente

✓ **Administrativas:**
- Desechos responsabilidad del cliente
- Trabajos adicionales requieren nueva cotización

**Campos a completar:**
- `[_____] días` → Tiempo estimado de ejecución

### 8. **FIRMA**
Sección de cierre con espacio para firma del representante.

**Campos a completar:**
- `[NOMBRE DEL REPRESENTANTE]`
- `[CARGO]`
- `[EMPRESA]`

## 📝 Paso a Paso para Crear una Nueva Cotización

### Paso 1: Duplicar la Plantilla
```
1. Abre PLANTILLA_COTIZACION_ESD_SIKAFLOOR.docx
2. Guarda como: [Número]-S-25_[CLIENTE]_ESD_Sikafloor260.docx
   Ejemplo: 335-S-25_CLIENTE_NUEVO_ESD_Sikafloor260.docx
```

### Paso 2: Completar Información del Cliente
- Número de cotización
- Fecha
- Nombre de la empresa
- Nombre y cargo de contacto

### Paso 3: Ingresar Especificaciones del Proyecto
- Superficie en m² y Ft²
- (Nota: 1 m² = 10.764 Ft²)

### Paso 4: Calcular Precios
- Consulta precio actual por m² con SIKA/proveedores
- Multiplica por superficie total
- Suma IVA 16%
- Suma otros costos si aplica

### Paso 5: Ajustar Tiempo de Proyecto
- Calcula días necesarios considerando superficie
- Generalmente: ~50 días para proyectos grandes

### Paso 6: Revisar Observaciones
- Verifica que todas apliquen
- Personaliza si el cliente tiene condiciones especiales

### Paso 7: Agregar Firma
- Ingresa nombre, cargo y empresa del representante

### Paso 8: Guardar y Enviar
- Guarda en formato .docx
- Imprime con logo de empresa si aplica
- Envía por correo al cliente

## 💡 Tips de Profesionalismo

### Colores y Formato
✓ Se utilizan azul corporativo (RGB 0, 51, 102) para encabezados
✓ Filas de tabla con fondo azul para secciones importantes
✓ Fuente estándar y legible en todo el documento

### Información Importante a Verificar
✓ Certificaciones ANSI S20.20 (especifica año: 2007 o 2014)
✓ Rango de resistencia: 1 x 10⁵ a 1 x 10⁹ Ω
✓ Especificaciones del material: SIKAFLOOR 260 ESD
✓ Espesores: 8 milésimas (aislamiento) + 12 milésimas (recubrimiento final)

### Campos Opcionales por Cliente
- **Proyectos pequeños:** Reduce plazo de entrega o ajusta términos
- **Clientes nuevos:** Puede requerirse anticipo del 70% o garantía
- **Proyectos internacionales:** Especifica moneda (USD vs MXN)
- **Área de El Paso, TX:** Incluye información de dirección en encabezado
